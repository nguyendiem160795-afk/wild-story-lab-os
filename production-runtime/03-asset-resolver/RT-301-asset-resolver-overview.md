# RT-301 Asset Resolver Overview

**Module:** 03-asset-resolver **Version:** 1.0.0

## Purpose

Asset Resolver chịu trách nhiệm xác định và tập hợp toàn bộ Asset cần
thiết trước khi Story Compiler thực thi.

## Responsibilities

-   Resolve Character
-   Resolve Environment
-   Resolve Props
-   Resolve Camera Presets
-   Resolve FX
-   Resolve Audio

## Output

Validated Asset Package
