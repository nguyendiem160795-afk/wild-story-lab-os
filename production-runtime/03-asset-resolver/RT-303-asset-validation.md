# RT-303 Asset Validation

**Module:** 03-asset-resolver\
**Version:** 1.0.0

## Purpose

Kiểm tra tính hợp lệ của mọi Asset trước khi chuyển sang Story Compiler.

## Validation Rules

-   Asset ID tồn tại
-   Đúng phiên bản
-   Không trùng lặp
-   Đúng định dạng
-   Có metadata

## Output

Asset Validation Report
