# RT-701 Flow Runtime Overview

**Module:** 07-flow-runtime **Version:** 1.0.0

## Purpose

Flow Runtime chịu trách nhiệm chuyển Prompt Package thành phiên làm việc
sẵn sàng cho Google Flow.

## Responsibilities

-   Build Flow Session
-   Organize Scene Queue
-   Export Prompt Order
-   Prepare Runtime Manifest

## Input

-   Prompt Package

## Output

Flow Execution Package
