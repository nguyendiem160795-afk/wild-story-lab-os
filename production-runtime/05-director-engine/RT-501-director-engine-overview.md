# RT-501 Director Engine Overview

**Module:** 05-director-engine\
**Version:** 1.0.0

## Purpose

Director Engine chuyển Story Package thành kế hoạch đạo diễn hoàn chỉnh
để Prompt Compiler có thể thực thi.

## Responsibilities

-   Build Shot List
-   Plan Camera
-   Plan Lighting
-   Plan Emotion
-   Plan Scene Timing

## Input

-   Story Package

## Output

Director Plan
