# RT-201 Context Engine Overview

**Module:** 02-context-engine\
**Version:** 1.0.0

## Purpose

Context Engine quản lý toàn bộ Runtime Context trong suốt vòng đời thực
thi.

## Responsibilities

-   Create Context
-   Update Context
-   Lock Context
-   Release Context

## Context Levels

-   Global
-   Project
-   Series
-   Episode
-   Scene
-   Task

## Output

Validated Runtime Context
