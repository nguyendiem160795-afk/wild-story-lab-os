# Purpose

Tài liệu này xác định các nguyên tắc ứng xử khi cộng tác và phát triển Module 11.

# Our Standards

Chúng tôi khuyến khích:

- Giao tiếp tôn trọng và chuyên nghiệp.
- Thảo luận dựa trên dữ liệu và tài liệu.
- Ưu tiên Documentation First.
- Đóng góp theo quy trình đã thống nhất.
- Giữ khả năng tương thích ngược khi có thể.

---

# Unacceptable Behavior

Không chấp nhận:

- Công kích cá nhân.
- Thay đổi tài liệu mà không ghi nhận.
- Phá vỡ Runtime Foundation không có đánh giá kiến trúc.
- Đưa mã hoặc tài liệu chưa được kiểm chứng vào nhánh phát hành.

---

# Contribution Principles

- Professionalize, not Rewrite
- Repository First
- Runtime First
- Semantic Versioning

---

# Enforcement

Các thay đổi lớn cần được:

1. Review.
2. Đánh giá tác động.
3. Cập nhật CHANGELOG.
4. Phê duyệt trước khi phát hành.
