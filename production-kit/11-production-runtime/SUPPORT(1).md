# Reporting an Issue

Khi tạo Issue, vui lòng cung cấp:

1. Runtime Version
2. Project ID (nếu có)
3. Mô tả vấn đề
4. Các bước tái hiện
5. Kết quả mong đợi
6. Kết quả thực tế
7. Runtime Log hoặc ảnh minh họa (nếu có)
