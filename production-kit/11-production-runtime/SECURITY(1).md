# Reporting a Security Issue

Khi phát hiện lỗ hổng:

1. Không công khai ngay lập tức.
2. Ghi rõ cách tái hiện.
3. Mô tả ảnh hưởng.
4. Đính kèm Runtime Logs nếu có.
5. Chờ xác minh trước khi công bố.
