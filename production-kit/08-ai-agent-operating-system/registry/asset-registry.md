Version: **1.0.0**

# Purpose

The Asset Registry is the canonical inventory of all production assets managed by Module 08.

Assets include documentation, schemas, templates, examples, diagrams, images, icons, and other reusable resources.

---

# Asset Categories

| Category | Description |
|----------|-------------|
| Documentation | Markdown documentation |
| Schema | JSON schemas |
| Template | Reusable templates |
| Example | Reference implementations |
| Diagram | Architecture diagrams |
| Image | Images and illustrations |
| Icon | UI and branding icons |

# Registration Rules

- Every asset must have a unique Asset ID.
- Assets must be versioned.
- Assets must be traceable to their source.
- Deprecated assets remain in the registry until archived.

---

# Lifecycle

Create → Review → Approve → Register → Use → Maintain → Archive
