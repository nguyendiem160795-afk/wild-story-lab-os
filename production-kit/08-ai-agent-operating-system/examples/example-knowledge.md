# Summary

This knowledge object defines the approved narrative structure, quality standards, and production constraints for story generation.

---

# Canonical Knowledge

## Story Structure

Every story should include:

1. Hook
2. Introduction
3. Conflict
4. Escalation
5. Climax
6. Resolution

---

## Quality Rules

- Clear objective
- One primary storyline
- Age-appropriate language
- Positive ending
- Consistent character behavior

---

## Production Constraints

- Scene transitions should be logical.
- Visual actions should match narration.
- Story length should match requested duration.
- Output must be structured in Markdown.
