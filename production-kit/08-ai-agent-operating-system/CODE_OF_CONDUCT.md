# Code of Conduct

> Wild Story Lab OS
> Module 08 — AI Agent Operating System

Version: **1.0.0**

---

# Our Commitment

We aim to build a respectful, collaborative, and inclusive community around Wild Story Lab OS.

All contributors, reviewers, and maintainers are expected to communicate professionally and constructively.

---

# Expected Behavior

- Be respectful.
- Give constructive feedback.
- Focus on technical discussion.
- Welcome questions and learning.
- Document decisions clearly.
- Respect review outcomes.

---

# Unacceptable Behavior

- Personal attacks
- Harassment or discrimination
- Spam or intentional disruption
- Publishing confidential information
- Misrepresentation of project work

---

# Review Principles

- Review the change, not the person.
- Explain requested changes.
- Reference documentation when possible.
- Keep discussions transparent.

---

# Enforcement

Project maintainers may request revisions, pause discussions, or reject contributions that do not follow this Code of Conduct.

---

# Scope

Applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project collaboration
