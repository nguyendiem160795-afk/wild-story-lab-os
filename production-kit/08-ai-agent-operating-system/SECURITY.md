# Reporting a Security Issue

If you discover a security vulnerability:

1. Do not disclose it publicly.
2. Prepare a clear description of the issue.
3. Include reproduction steps, affected files, and impact.
4. Notify the maintainers through the project's private communication channel.
5. Wait for confirmation before public disclosure.

---

# Response Process

1. Acknowledge the report.
2. Assess severity.
3. Reproduce the issue.
4. Develop and review a fix.
5. Release a patched version.
6. Publish release notes if appropriate.
