The `assets/icons/` directory contains reusable icon assets for documentation, branding, dashboards, and future runtime interfaces.

# Asset Types

- Application icons
- Module icons
- Agent icons
- Workflow icons
- Status badges
- Brand logos

# Preferred Formats

| Format | Use Case |
|--------|----------|
| .svg | Primary format (scalable) |
| .png | Compatibility |
| .ico | Application icon |
| .webp | Web optimization |

# Naming Convention

Examples:

```text
agent.svg
```

---

# Best Practices

- Prefer SVG whenever possible.
- Maintain consistent visual style.
- Export optimized files only.
- Keep source artwork in a separate design repository if applicable.
