# Purpose

The `assets/images/` directory stores reusable image assets that support documentation, tutorials, presentations, and production workflows.

These images provide visual references for both developers and content creators.

---

# Image Categories

- Documentation screenshots
- User interface references
- Architecture illustrations
- Workflow examples
- Character reference images
- Branding graphics
- Presentation visuals

---

# Preferred Formats

| Format | Recommended Use |
|--------|------------------|
| .png | Documentation and UI captures |
| .jpg | Photographic content |
| .webp | Optimized web delivery |
| .svg | Vector illustrations |

---

# Naming Convention

Use lowercase names with hyphens.

Examples:

```text
agent-dashboard.png
workflow-overview.png
story-planner-ui.webp
architecture-overview.svg
character-reference.png
```

---

# Best Practices

- Use high-resolution source images.
- Compress images before committing.
- Avoid duplicate assets.
- Store editable source files separately when possible.
- Reference images using repository-relative paths.
