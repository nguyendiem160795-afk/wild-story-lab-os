# AI Director Workflow

## Purpose

Định nghĩa quy trình chuẩn của Module 10 AI Director System.

## End-to-End Workflow

1. Receive Story Blueprint
2. Analyze Story
3. Plan Scenes
4. Direct Camera
5. Direct Characters
6. Compose Prompts
7. Validate Prompts
8. Run Quality Assurance
9. Build Production Package
10. Release Package
