# DIR-002 Director Workflow

## Metadata

ID: DIR-002
Module: 10 AI Director System
Category: Director Core
Version: 1.0.0
Status: Active

## Purpose

Định nghĩa quy trình làm việc chuẩn của AI Director từ khi nhận Story cho đến khi xuất Prompt Package hoàn chỉnh.

## Workflow Overview

Story
→ Story Analysis
→ Scene Planning
→ Shot Planning
→ Character Direction
→ Camera Direction
→ Lighting & FX
→ Audio Direction
→ Prompt Assembly
→ Quality Validation
→ Export Package

## Workflow Stages

### Stage 01 — Story Intake
- Nhận Story từ Story Engine
- Kiểm tra dữ liệu đầu vào
- Phân tích mục tiêu video

### Stage 02 — Story Analysis
- Xác định Hook
- Xác định WOW
- Xác định Climax
- Xác định Ending

### Stage 03 — Scene Planning
- Chia Scene
- Xác định Story Beats
- Phân bổ thời lượng

### Stage 04 — Shot Planning
- Chọn Shot
- Chọn Lens
- Chọn Camera Movement
- Chọn Composition

### Stage 05 — Production Direction
- Character Acting
- Emotion
- FX
- Audio

### Stage 06 — Prompt Generation
- Ghép Prompt Blocks
- Kiểm tra Consistency
- Tối ưu theo nền tảng

### Stage 07 — Quality Assurance
- Prompt Validation
- Story Validation
- Character Validation
- Production Validation

### Stage 08 — Export
- Prompt Package
- Shot List
- Camera Plan
- Production Report

## Inputs

- Story Engine
- Character Bible
- Production Components
- Prompt Components

## Outputs

- Scene Blueprint
- Shot Blueprint
- Prompt Package
- QA Report

## Dependencies

- Module 05 Story Engine
- Module 08 AI Agent OS
- Module 09 Production Components
