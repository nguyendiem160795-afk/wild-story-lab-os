# DIR-031 Visual QA

## Metadata

ID: DIR-031
Module: 10 AI Director System
Category: Quality Intelligence
Version: 1.0.0
Status: Active

## Purpose

Visual QA chịu trách nhiệm kiểm định chất lượng hình ảnh trước khi Prompt được xuất sang nền tảng AI Video.

## Responsibilities

- Kiểm tra Character Consistency
- Kiểm tra Camera Consistency
- Kiểm tra Lighting
- Kiểm tra Composition
- Kiểm tra FX
- Kiểm tra Visual Continuity

## Inputs

- Scene Blueprint
- Camera Plan
- Lighting Plan
- Composition Plan
- FX Plan
- Render Preview (nếu có)

## Validation Categories

### Character
- Character DNA
- Outfit
- Scale
- Color Palette

### Cinematic
- Camera Angle
- Lens
- Framing
- Depth

### Visual
- Exposure
- Contrast
- Color Harmony
- Visual Noise

## QA Workflow

Load Scene
→ Visual Inspection
→ Consistency Check
→ Issue Detection
→ QA Report

## Outputs

- Visual QA Report
- Error List
- Improvement Suggestions
- Visual Score

## Acceptance Criteria

- Character Consistency ≥ 95
- Visual Continuity ≥ 95
- Composition PASS
- Lighting PASS

Status: Approved
