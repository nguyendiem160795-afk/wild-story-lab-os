# DIR-027 Prompt Optimizer

## Metadata

ID: DIR-027
Module: 10 AI Director System
Category: Prompt Orchestrator
Version: 1.0.0
Status: Active

## Purpose

Prompt Optimizer chịu trách nhiệm cải thiện Prompt sau khi đã vượt qua bước Validation nhằm tăng chất lượng đầu ra, giảm xung đột và tối ưu cho từng nền tảng AI Video.

## Responsibilities

- Tối ưu cấu trúc Prompt
- Loại bỏ thông tin dư thừa
- Hợp nhất Prompt Blocks
- Chuẩn hóa ngôn ngữ
- Tối ưu theo Platform Profile
- Cải thiện khả năng sinh hình/video

## Inputs

- Master Prompt
- Validation Report
- Platform Profile
- Quality Score

## Optimization Pipeline

Load Prompt
→ Analyze Complexity
→ Remove Redundancy
→ Resolve Conflicts
→ Platform Optimization
→ Readability Check
→ Optimized Prompt

## Optimization Strategies

### Structural
- Remove duplicate instructions
- Merge compatible blocks
- Normalize ordering

### Semantic
- Increase clarity
- Strengthen cinematic language
- Preserve story intent

### Platform
- Google Flow Optimization
- Veo Optimization
- Runway Optimization
- Sora Optimization
- Luma Optimization

## Outputs

- Optimized Master Prompt
- Platform-specific Prompt
- Optimization Report
- Optimization Score

## Validation Rules

- Không làm thay đổi Story Goal.
- Không thay đổi Character DNA.
- Không mất thông tin quan trọng.
- Prompt ngắn gọn nhưng đầy đủ.
- Sẵn sàng cho Platform Adapter.

## Dependencies

- DIR-025 Prompt Composer
- DIR-026 Prompt Validator
- Module 09 Prompt Components
