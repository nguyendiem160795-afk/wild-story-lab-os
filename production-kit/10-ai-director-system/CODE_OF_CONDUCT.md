# Purpose

# Our Values

- Documentation First
- Story First
- Quality First
- Repository First
- Continuous Improvement
- Respect & Collaboration

---

# Expected Behavior

Thành viên nên:

- Viết tài liệu rõ ràng.
- Tôn trọng cấu trúc Repository.
- Giữ tính nhất quán của Module.
- Đóng góp mang tính xây dựng.
- Chia sẻ kiến thức.

---

# Unacceptable Behavior

Không chấp nhận:

- Phá vỡ cấu trúc tài liệu.
- Xóa tài liệu mà không có lý do.
- Thay đổi kiến trúc không được ghi nhận.
- Đưa nội dung không liên quan vào Repository.

# Documentation Rules

- README luôn là điểm bắt đầu.

- Mọi thay đổi lớn phải cập nhật CHANGELOG.
