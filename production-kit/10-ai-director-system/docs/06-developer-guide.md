# Purpose

# Repository Structure

```text
10-ai-director-system/
├── README.md
├── docs/
├── ARCHITECTURE.md
├── WORKFLOW.md
├── PIPELINE.md
├── *_SPEC.md
└── CHANGELOG.md
```

---

# Development Workflow

1. Đọc README.md
2. Tham khảo docs/
3. Thiết kế thay đổi
4. Cập nhật tài liệu liên quan
5. Kiểm tra Quality Gate
6. Commit thay đổi
7. Cập nhật CHANGELOG

---

# Naming Convention

- Tên file: UPPER_CASE hoặc kebab-case theo chuẩn module.
- File đặc tả: `*_SPEC.md`
- Tài liệu hướng dẫn: `docs/*.md`

---

# Documentation Standards

- Một tài liệu chỉ tập trung vào một chủ đề.
- Sử dụng tiêu đề rõ ràng.
- Liên kết tới tài liệu liên quan.
- Cập nhật Version khi thay đổi lớn.

---

# Best Practices

- Story First.
- Documentation First.
- Repository First.
- Không sửa trực tiếp tài liệu đã phát hành nếu chưa cập nhật CHANGELOG.
- Giữ tính nhất quán giữa README, docs và các file kỹ thuật.
