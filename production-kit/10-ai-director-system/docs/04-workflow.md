# 04 - Workflow

# AI Director Workflow

> Wild Story Lab OS / Production Kit

---

# Purpose

Tài liệu này mô tả quy trình vận hành chuẩn (Workflow) của AI Director System, từ khi tiếp nhận yêu cầu sản xuất cho đến khi phát hành Production Package và Release Package.

---

# End-to-End Workflow

```text
User Request
      │
      ▼
Story Analysis
      │
      ▼
Story Planning
      │
      ▼
Scene Planning
      │
      ▼
Shot Planning
      │
      ▼
Character Direction
      │
      ▼
Camera Direction
      │
      ▼
Prompt Generation
      │
      ▼
Quality Assurance
      │
      ▼
Production Package
      │
      ▼
Release Package
```

---

# Workflow Stages

## Stage 1 — Story Analysis

Objectives

- Hiểu mục tiêu câu chuyện
- Phân tích Story Blueprint
- Xác định Story Goal
- Kiểm tra World Rules

Outputs

- Story Analysis Report
- Story Plan

---

## Stage 2 — Story Planning

Responsibilities

- Story Beats
- Scene Breakdown
- Emotional Arc
- Production Strategy

Outputs

- Story Blueprint
- Scene Plan

---

## Stage 3 — Scene Planning

Responsibilities

- Scene Timeline
- Character Allocation
- Environment Planning
- Scene Dependencies

Outputs

- Scene Blueprint

---

## Stage 4 — Shot Planning

Responsibilities

- Camera Shot List
- Lens Selection
- Motion Planning
- Lighting Planning
- Composition

Outputs

- Shot List
- Cinematic Blueprint

---

## Stage 5 — Character Direction

Responsibilities

- Character DNA Validation
- Acting Direction
- Emotion Planning
- Dialogue Review

Outputs

- Character Direction Plan

---

## Stage 6 — Prompt Generation

Responsibilities

- Master Prompt
- Scene Prompt
- Platform Prompt
- Prompt Optimization
- Prompt Validation

Supported Platforms

- Google Flow
- Veo
- Runway
- Sora
- Luma

Outputs

- Prompt Package

---

## Stage 7 — Quality Assurance

Quality Gates

- Story QA
- Character QA
- Visual QA
- Prompt QA
- Continuity QA
- Release QA

Outputs

- QA Report
- Quality Score

---

## Stage 8 — Production

Responsibilities

- Package Assembly
- Manifest Generation
- Asset Validation
- Release Preparation

Outputs

- Production Package
- Release Package

---

# Workflow Principles

- Story First
- One Source of Truth
- Quality by Default
- Multi-Agent Collaboration
- Documentation Driven
- Repository First
