# Purpose

Tài liệu này cung cấp các ví dụ minh họa giúp hiểu cách AI Director vận hành trong thực tế, từ Story đến Release.

---

# Example 1 — End-to-End Production

```text
User Request
      │
      ▼
Story Analysis
      ▼
Story Planning
      ▼
Scene Planning
      ▼
Shot Planning
      ▼
Prompt Generation
      ▼
Quality Assurance
      ▼
Production Package
      ▼
Release Package
```

Kết quả:

- Story Blueprint
- Prompt Package
- QA Report
- Production Package

---

# Example 2 — Multi-Agent Collaboration

```text
AI Director
    │
    ├── Story Agent
    ├── Character Agent
    ├── Camera Agent
    ├── Prompt Agent
    ├── QA Agent
    └── Release Agent
```

Vai trò:

- AI Director điều phối.
- Mỗi Agent xử lý đúng chuyên môn.
- QA xác nhận trước khi phát hành.
