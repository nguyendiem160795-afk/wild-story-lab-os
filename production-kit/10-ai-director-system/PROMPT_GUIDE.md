# AI Director Prompt Guide

Version: 1.0.0
Status: Stable

## Purpose

Tài liệu này định nghĩa tiêu chuẩn xây dựng Prompt trong Module 10 AI Director System nhằm đảm bảo Prompt nhất quán, đầy đủ và tối ưu cho các nền tảng AI Video.

---

## Standard Prompt Structure

1. Subject
2. Action
3. Environment
4. Camera
5. Lens
6. Composition
7. Lighting
8. Motion
9. Emotion
10. FX
11. Style
12. Rendering Quality

## Platform Rules

### Google Flow
- Scene-first
- Character consistency
- Camera-first syntax

### Veo
- Cinematic language
- Rich motion
- Natural description

### Runway
- Camera-centric
- Short prompt
- Fast iteration

### Sora
- Long-form narrative
- Physical consistency
- Temporal continuity

### Luma
- Motion-first
- Dynamic environment

---

## Best Practices

- Một Prompt chỉ có một mục tiêu chính.
- Giữ Character DNA nhất quán.
- Camera luôn phục vụ Story.
- Không thêm chi tiết mâu thuẫn.
- Luôn kiểm tra Prompt bằng Prompt QA.

---

## Common Mistakes

- Thiếu Camera.
- Thiếu Lighting.
- Thiếu Subject.
- Prompt quá dài.
- Prompt mâu thuẫn.
