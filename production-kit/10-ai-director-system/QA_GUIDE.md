# QA_GUIDE.md

# AI Director Quality Assurance Guide

Version: 1.0.0
Status: Stable

## Purpose

QA Guide định nghĩa toàn bộ tiêu chuẩn kiểm định chất lượng của Module 10 AI Director System trước khi Prompt hoặc Production Package được phát hành.

---

# QA Framework

Module 10 sử dụng 5 tầng kiểm định:

1. Story QA
2. Visual QA
3. Prompt QA
4. Continuity QA
5. Release QA

Mọi tầng phải PASS trước khi Release.

---

# Story QA

## Checklist

- Story Goal rõ ràng
- Hook mạnh
- Conflict tăng dần
- Climax đủ cao
- Ending hoàn chỉnh
- Emotional Arc hợp lý

PASS SCORE ≥ 90

---

# Visual QA

## Checklist

- Character DNA nhất quán
- Camera đúng kế hoạch
- Lens đúng
- Lighting đúng
- Composition rõ ràng
- FX không gây nhiễu

PASS SCORE ≥ 90

---

# Prompt QA

## Checklist

- Subject đầy đủ
- Action rõ ràng
- Camera hợp lệ
- Lighting hợp lệ
- Style hợp lệ
- Platform tương thích

PASS SCORE ≥ 90

---

# Continuity QA

## Checklist

- Character Continuity
- Camera Direction
- Timeline
- Props
- Costume
- Environment

PASS SCORE ≥ 95

---

# Release QA

## Checklist

✓ README

✓ INDEX

✓ CHANGELOG

✓ Manifest

✓ QA Reports

✓ Prompt Package

✓ Production Package

PASS = 100%

---

# Error Severity

Critical
- Không được Release

Major
- Bắt buộc sửa

Minor
- Khuyến nghị sửa

Info
- Chỉ ghi nhận
