# Example 4 --- Archive an Obsolete Prompt

**Skill:** PB-097 Archive AI Asset

**Scenario**

A deprecated prompt is no longer used after a new production workflow
replaces it.

**Expected Output**

-   Status changed to Archived
-   Search visibility removed
-   History preserved

------------------------------------------------------------------------

# Example 5 --- Restore an Archived Character

**Skill:** PB-098 Restore Archived Asset

**Scenario**

The character "Mochi" is required for a new series.

**Expected Output**

-   Status restored to Active
-   Metadata retained
-   Audit trail updated

------------------------------------------------------------------------

# Example 6 --- Retire an AI Asset

**Skill:** PB-100 Retire AI Asset

**Scenario**

An obsolete workflow is permanently retired.

**Expected Output**

-   Asset lifecycle closed
-   Historical records retained
-   No further production usage

------------------------------------------------------------------------

# Best Practices

-   Register every AI asset before use.
-   Keep metadata complete and consistent.
-   Archive instead of deleting whenever possible.
-   Preserve audit history.
-   Use standardized naming conventions.
