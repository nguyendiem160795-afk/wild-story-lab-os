# PB-008 --- Validate Prompt Package

> **Module:** 07-playbook-os\
> **Playbook ID:** PB-008\
> **Version:** 1.0.0\
> **Status:** Stable

------------------------------------------------------------------------

# Executive Summary

Validate that a Prompt Package is complete, consistent, reusable, and
production-ready before it enters the production pipeline.

------------------------------------------------------------------------

# Purpose

Ensure every Prompt Package generated by PB-007 satisfies Wild Story Lab
OS quality standards and can be executed without additional
clarification.

------------------------------------------------------------------------

# Business Value

-   Prevent prompt quality issues before production.
-   Ensure character and story consistency.
-   Reduce generation failures.
-   Improve prompt reuse across projects.
-   Maintain a reliable production pipeline.

------------------------------------------------------------------------

# Scope

## Included

-   Prompt completeness
-   Character consistency
-   Story alignment
-   Platform compatibility
-   Prompt quality review
-   Final production approval

## Excluded

-   Prompt creation
-   Image generation
-   Video rendering
-   Publishing

------------------------------------------------------------------------

# Prerequisites

-   PB-007 Create Prompt Package completed.
-   Approved Content Blueprint.
-   Approved Story Package.
-   Approved Character Package.

------------------------------------------------------------------------

# Inputs

-   Prompt Package
-   Content Blueprint
-   Story Package
-   Character Package
-   Brand Guidelines (optional)

------------------------------------------------------------------------

# Outputs

-   Approved Prompt Package
-   Validation Report
-   Improvement Notes (if required)

------------------------------------------------------------------------

# Validation Workflow

1.  Load Prompt Package.
2.  Verify required prompt components.
3.  Check Character consistency.
4.  Check Story consistency.
5.  Verify visual style.
6.  Verify platform variants.
7.  Record validation results.
8.  Approve or reject Prompt Package.

------------------------------------------------------------------------

# Validation Checklist

  Check                               Pass
  ---------------------------------- ------
  Master Prompt exists                 ☐
  Character Prompt exists              ☐
  Scene Prompts complete               ☐
  Environment Prompt included          ☐
  Camera instructions defined          ☐
  Style Prompt defined                 ☐
  Negative Prompt included             ☐
  Platform variants available          ☐
  Character consistency maintained     ☐
  Story consistency maintained         ☐

------------------------------------------------------------------------

# Decision Rules

  Result            Action
  ----------------- ------------------------------------
  All checks pass   Approve Prompt Package
  Minor issues      Return for revision
  Major issues      Reject and recreate Prompt Package

------------------------------------------------------------------------

# Success Criteria

-   Package is complete.
-   Character remains consistent.
-   Story intent is preserved.
-   Ready for AI production.
-   No critical validation issues remain.

------------------------------------------------------------------------

# Deliverables

-   Approved Prompt Package
-   Validation Checklist
-   Validation Report

------------------------------------------------------------------------

# Best Practices

-   Validate against approved assets only.
-   Never approve incomplete prompt sets.
-   Keep validation objective and repeatable.
-   Record all rejected items with reasons.

------------------------------------------------------------------------

# Common Mistakes

-   Missing negative prompts.
-   Inconsistent character descriptions.
-   Different visual styles between scenes.
-   Missing platform-specific prompts.
