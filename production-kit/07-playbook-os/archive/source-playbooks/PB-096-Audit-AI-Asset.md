# Executive Summary

Perform a structured audit of AI assets to verify governance,
compliance, quality, ownership, security, and lifecycle records.

# Purpose

Ensure every AI asset remains compliant with organizational standards
throughout its lifecycle.

------------------------------------------------------------------------

# Business Value

-   Detect governance gaps
-   Improve compliance
-   Increase traceability
-   Reduce operational risk
-   Support continuous improvement

------------------------------------------------------------------------

# Prerequisites

-   PB-091 through PB-095 completed
-   Asset available for audit
-   Audit criteria approved

------------------------------------------------------------------------

# Inputs

-   Asset ID
-   Asset registry record
-   Metadata
-   Ownership record
-   Quality validation report
-   Audit checklist

------------------------------------------------------------------------

# Outputs

-   Audit report
-   Compliance status
-   Findings register
-   Corrective action plan
-   Audit log

------------------------------------------------------------------------

# Workflow

1.  Select the AI asset for audit.
2.  Review registration and classification records.
3.  Verify metadata accuracy.
4.  Confirm ownership information.
5.  Review quality validation evidence.
6.  Evaluate compliance against standards.
7.  Record findings and risks.
8.  Assign corrective actions where required.
9.  Publish the audit report and update the audit log.

------------------------------------------------------------------------

# Decision Rules

  Condition                 Action
  ------------------------- ---------------------------
  Critical non-compliance   Escalate immediately
  Minor findings            Create corrective actions
  No findings               Close audit successfully

-   Preserve objective evidence.
-   Track corrective actions to closure.

# Common Mistakes

-   Missing follow-up actions.
-   Poor documentation of findings.
