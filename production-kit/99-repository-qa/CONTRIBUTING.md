# Purpose

Tài liệu này hướng dẫn cách đóng góp và cập nhật Module 99 một cách nhất quán.

---

# Contribution Workflow

1. Tạo hoặc cập nhật tài liệu.
2. Kiểm tra định dạng Markdown.
3. Cập nhật CHANGELOG nếu có thay đổi đáng kể.
4. Chạy QA theo Module 99.
5. Chỉ tạo Pull Request sau khi QA đạt.

---

# Documentation Standards

- Một tài liệu chỉ phục vụ một mục đích.
- Sử dụng tên file chuẩn.
- Cập nhật MODULE_MANIFEST khi thêm hoặc xóa tài liệu.
- Cập nhật MODULE_INDEX khi thay đổi cấu trúc.

---

# Pull Request Checklist

- [ ] Documentation updated
- [ ] Internal links verified
- [ ] Version synchronized
- [ ] QA completed
- [ ] CHANGELOG updated

---

# Review Criteria

- Tính chính xác
- Tính nhất quán
- Khả năng tái sử dụng
- Khả năng bảo trì
