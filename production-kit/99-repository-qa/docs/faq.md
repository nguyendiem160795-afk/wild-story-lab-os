# Frequently Asked Questions

## Q1. Khi nào cần chạy Module 99?

Sau khi một module hoàn thành và trước khi phát hành lên GitHub hoặc Production.

---

## Q2. Module 99 có sửa nội dung module không?

Không.

Module 99 đánh giá, xác nhận và đưa ra khuyến nghị. Việc sửa nội dung thuộc về module đang được kiểm định.

---

## Q3. Điều kiện để một module đạt GitHub Ready?

- Documentation hoàn chỉnh
- QA Checklist đạt
- Không còn Critical Issues
- Release Approval được phê duyệt
- Version đồng bộ

---

## Q4. Nếu QA không đạt thì sao?

Module sẽ quay lại giai đoạn chỉnh sửa, sau đó thực hiện QA lại cho đến khi đạt yêu cầu.

---

## Q5. Có cần chạy Module 99 cho mọi phiên bản không?

Có.

Khuyến nghị áp dụng cho mọi bản phát hành Major, Minor và các bản Patch quan trọng.

---

## Q6. Module 99 có thay thế Code Review không?

Không.

Module 99 bổ sung quy trình QA tài liệu, cấu trúc repository và quy trình phát hành. Code Review vẫn nên được thực hiện nếu repository có mã nguồn.
