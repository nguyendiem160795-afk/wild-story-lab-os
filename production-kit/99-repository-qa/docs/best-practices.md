# Purpose

Tài liệu này tổng hợp các thực hành tốt nhất (Best Practices) khi kiểm định chất lượng và phát hành repository.

---

# Documentation

## Always

- Viết README đầy đủ.
- Cập nhật CHANGELOG khi có thay đổi.
- Đồng bộ Version trên toàn bộ tài liệu.
- Duy trì MODULE_INDEX và MODULE_MANIFEST.

---

# Repository

## Recommended

- Một mục đích cho mỗi tài liệu.
- Không lưu file trùng lặp.
- Không giữ file tạm trong repository.
- Sử dụng cấu trúc thư mục thống nhất.

---

# Quality Assurance

- Thực hiện QA trước mọi lần phát hành.
- Không bỏ qua bất kỳ mục nào trong QA_CHECKLIST.
- Ghi nhận đầy đủ các lỗi và khuyến nghị.
- Chỉ phát hành khi không còn Critical Issues.

---

# Release

Trước khi phát hành:

- QA Report hoàn tất.
- Release Approval được ký.
- Final Build Report đã tạo.
- Completion Certificate đã cập nhật.

---

# Continuous Improvement

Sau mỗi lần phát hành:

- Rút kinh nghiệm từ QA.
- Cập nhật Best Practices nếu cần.
- Cải tiến quy trình nhưng vẫn đảm bảo khả năng tương thích.
