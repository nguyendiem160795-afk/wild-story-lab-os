# Recommended License

Đối với dự án mã nguồn mở, khuyến nghị sử dụng một giấy phép rõ ràng ở cấp repository, ví dụ:

- MIT License
- Apache License 2.0
- GPL v3

Module 99 không áp đặt loại giấy phép, nhưng yêu cầu toàn bộ repository chỉ sử dụng một giấy phép thống nhất.

- Cập nhật khi thay đổi chính sách phân phối.
