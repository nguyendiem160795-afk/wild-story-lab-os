# Naming Convention

## Production Component ID

Format:

PCL-###-ComponentName

Examples:

PCL-001-Camera-Library
PCL-010-Shot-Library
PCL-028-Hook-Library

## File Naming

- PascalCase for titles
- kebab-case for filenames
- Markdown: .md
- Images: .png, .jpg, .webp
- Video: .mp4

## Versioning

vMajor.Minor.Patch

Example:

v1.0.0
v1.1.0
v2.0.0

Status: Approved
