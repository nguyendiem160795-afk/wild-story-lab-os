# Versioning Policy

## Version Format

Module 09 tuân theo Semantic Versioning:

MAJOR.MINOR.PATCH

Ví dụ:

- v1.0.0
- v1.1.0
- v1.2.3
- v2.0.0

## Rules

### MAJOR
- Thay đổi kiến trúc
- Thay đổi không tương thích

### MINOR
- Thêm Production Component Library mới
- Thêm tính năng nhưng vẫn tương thích

### PATCH
- Sửa lỗi
- Cải thiện tài liệu
- Tối ưu nội dung

## Release Tags

- Alpha
- Beta
- Release Candidate (RC)
- Stable
