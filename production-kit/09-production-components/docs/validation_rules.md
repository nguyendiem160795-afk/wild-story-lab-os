# Validation Rules

## Purpose

Định nghĩa các quy tắc kiểm tra để đảm bảo mọi Production Component Library (PCL) đều đạt tiêu chuẩn trước khi được đưa vào Wild Story Lab OS.

## Validation Rules

### Metadata
- [ ] Có ID PCL hợp lệ
- [ ] Có Name
- [ ] Có Category
- [ ] Có Version
- [ ] Có Status

### Content
- [ ] Có mô tả chức năng
- [ ] Có hướng dẫn sử dụng
- [ ] Có ví dụ Prompt
- [ ] Có Dependencies (nếu có)

### Repository
- [ ] Đúng cấu trúc thư mục
- [ ] Không trùng Component ID
- [ ] Markdown hợp lệ
- [ ] UTF-8 Encoding

### Review
- [ ] Technical Review
- [ ] QA Review
- [ ] Final Approval
