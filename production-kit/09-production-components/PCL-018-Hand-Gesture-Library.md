# PCL-018 Hand Gesture Library

## Metadata

ID: PCL-018
Category: Character Animation
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa cử chỉ bàn tay để tăng khả năng giao tiếp phi ngôn ngữ và làm cho nhân vật trở nên sống động.

## Gesture Types

- Wave
- Point
- Thumbs Up
- Thumbs Down
- Open Palm
- Closed Fist
- Clap
- High Five
- Peace Sign
- Finger Count
- Heart Gesture
- Hands Together
- Hands On Hips
- Holding Object
- Reach Out

## Animation Principles

- Natural wrist rotation
- Finger follow-through
- Smooth transitions
- Consistent timing
- Secondary motion

## Prompt Example

Mochi waves enthusiastically with an open palm, relaxed fingers, smooth wrist movement, expressive Pixar-style hand animation.

## Best Practices

- Đồng bộ cử chỉ với biểu cảm khuôn mặt.
- Tránh chuyển động tay quá nhanh.
- Duy trì tỷ lệ tay nhất quán.
- Kết hợp với Action Library và Facial Animation.

## Dependencies

- PCL-016 Character Animation Library
- PCL-017 Facial Animation Library
- PCL-021 Action Library
