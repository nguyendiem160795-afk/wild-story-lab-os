# PCL-011 Lens Library

## Metadata

ID: PCL-011
Category: Cinematic Components
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa các loại ống kính (Lens) để tạo chiều sâu, phối cảnh và cảm xúc nhất quán trong AI Video.

## Lens Types

- 14mm Ultra Wide
- 24mm Wide
- 35mm Standard Wide
- 50mm Standard
- 85mm Portrait
- 135mm Telephoto
- 200mm Super Telephoto
- Macro Lens

## Recommended Usage

| Lens | Use Case |
|------|----------|
| 14mm | Large environments |
| 24mm | Establishing shots |
| 35mm | General storytelling |
| 50mm | Natural perspective |
| 85mm | Character portraits |
| 135mm | Emotional close-ups |
| Macro | Tiny details |

## Prompt Example

Camera: 85mm portrait lens, cinematic close-up, soft bokeh background, golden hour lighting.

## Best Practices

- 50mm cho cảnh tự nhiên.
- 85mm cho chân dung.
- Macro cho chi tiết nhỏ.
- Kết hợp với DOF để tăng chiều sâu.

## Dependencies

- PCL-001 Camera Library
- PCL-010 Shot Library
- PCL-013 Depth of Field Library
