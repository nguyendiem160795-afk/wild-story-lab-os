# PCL-017 Facial Animation Library

## Metadata

ID: PCL-017
Category: Character Animation
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa biểu cảm khuôn mặt để đảm bảo nhân vật truyền tải cảm xúc rõ ràng và nhất quán.

## Facial Expressions

- Happy
- Excited
- Curious
- Surprised
- Sad
- Angry
- Scared
- Confused
- Proud
- Sleepy
- Thinking
- Laughing

## Facial Controls

- Eyebrows
- Eyes
- Eyelids
- Pupils
- Nose
- Cheeks
- Mouth
- Teeth
- Tongue
- Chin

## Prompt Example

Mochi smiles with sparkling eyes, raised eyebrows, soft cheeks, open-mouth laugh, expressive Pixar-style facial animation.

## Best Practices

- Đồng bộ khuôn mặt với lời thoại.
- Tránh thay đổi biểu cảm quá đột ngột.
- Mắt luôn là điểm nhấn chính.
- Kết hợp với Eye Contact Library.

## Dependencies

- PCL-003 Expression Library
- PCL-019 Eye Contact Library
