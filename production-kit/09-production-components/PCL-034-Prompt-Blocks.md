# PCL-034 Prompt Blocks

## Metadata

ID: PCL-034
Category: Prompt Components
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa các khối Prompt (Prompt Blocks) để Director Agent có thể tự động lắp ráp prompt điện ảnh cho Google Flow, Veo, Sora, Runway và các AI Video khác.

## Prompt Block Structure

1. Subject
2. Environment
3. Action
4. Camera
5. Lens
6. Lighting
7. Composition
8. Emotion
9. FX
10. Style
11. Motion
12. Output Quality

## Prompt Assembly Order

Subject
→ Environment
→ Action
→ Camera
→ Lens
→ Lighting
→ FX
→ Style
→ Quality

## Prompt Example

Cute Shiba Inu named Mochi, magical bakery, happily baking cookies, medium close-up, 50mm lens, warm cinematic lighting, floating magical sparkles, Pixar-style, smooth animation, ultra high quality.

## Best Practices

- Một Prompt Block cho một nhiệm vụ.
- Không lặp thông tin.
- Dễ tái sử dụng.
- Tương thích đa nền tảng AI Video.
