# PCL-014 Focus Library

## Metadata

ID: PCL-014
Category: Cinematic Components
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa các kỹ thuật lấy nét (Focus) để điều hướng sự chú ý của người xem và tăng chất lượng điện ảnh.

## Focus Types

- Auto Focus
- Manual Focus
- Single Point Focus
- Continuous Focus
- Face Detection Focus
- Eye Tracking Focus
- Rack Focus
- Infinity Focus

## Recommended Usage

| Focus Type | Best Use |
|------------|----------|
| Single Point | Chủ thể tĩnh |
| Continuous | Chủ thể di chuyển |
| Face Detection | Cận cảnh nhân vật |
| Eye Tracking | Hội thoại, cảm xúc |
| Rack Focus | Chuyển trọng tâm giữa hai chủ thể |
| Infinity | Phong cảnh |

## Prompt Example

Focus on Mochi's eyes with eye tracking focus, shallow depth of field, soft cinematic lighting, background smoothly blurred.

## Best Practices

- Ưu tiên Eye Tracking cho nhân vật.
- Kết hợp Rack Focus với chuyển động máy quay.
- Đồng bộ Focus với Lens và DOF.
- Tránh thay đổi điểm nét quá nhanh gây mất tập trung.
