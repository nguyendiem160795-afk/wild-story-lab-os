# Contributing

## Purpose

Hướng dẫn đóng góp cho Module 09 Production Components.

## Rules

- Tuân thủ chuẩn đặt tên PCL.
- Mỗi Production Component là một đơn vị tái sử dụng.
- Không sửa các Library đã phát hành, chỉ tạo phiên bản mới.
- Cập nhật CHANGELOG khi thêm Library.
- Kiểm tra tính tương thích với Story Engine và Prompt Engine.

## Pull Request

- Có mô tả thay đổi.
- Có tài liệu nếu bổ sung Library mới.
- Đảm bảo không phá vỡ cấu trúc hiện có.
