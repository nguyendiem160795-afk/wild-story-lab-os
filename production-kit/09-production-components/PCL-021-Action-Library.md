# PCL-021 Action Library

## Metadata

ID: PCL-021
Category: Character Animation
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa các hành động phổ biến để Story Engine, Director Agent và Prompt Engine có thể tái sử dụng trên nhiều video.

## Action Categories

### Basic Actions
- Walk
- Run
- Jump
- Sit
- Stand
- Turn
- Stop

### Interaction
- Pick Up
- Put Down
- Push
- Pull
- Open
- Close
- Throw
- Catch

### Communication
- Wave
- Point
- Clap
- Hug
- High Five
- Nod
- Shake Head

### Emotional Actions
- Laugh
- Cry
- Celebrate
- Dance
- Hide
- Peek
- Cheer

## Prompt Example

Mochi happily runs toward the camera, waves with one hand, jumps excitedly, then celebrates with expressive Pixar-quality body animation.

## Best Practices

- Chỉ một hành động chính trong mỗi cảnh.
- Chuyển tiếp giữa các hành động mượt mà.
- Đồng bộ với Facial Animation và Hand Gestures.
- Giữ silhouette rõ ràng để AI tái tạo ổn định.
