# PCL-036 Negative Prompt Library

## Metadata

ID: PCL-036
Category: Prompt Components
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa Negative Prompt để loại bỏ các lỗi thường gặp khi tạo AI Video và đảm bảo tính nhất quán của nhân vật.

## Negative Prompt Categories

### Character Errors
- extra limbs
- missing fingers
- duplicated character
- deformed face
- crossed eyes
- inconsistent proportions

### Animation Errors
- jitter
- flickering
- broken motion
- frozen pose
- unnatural movement

### Image Quality
- blurry
- low quality
- noisy
- artifact
- watermark
- text
- logo

### Composition Errors
- cropped subject
- bad framing
- wrong perspective
- overexposed
- underexposed

## Prompt Example

Negative prompt: blurry, low quality, watermark, text, logo, extra limbs, duplicated character, deformed face, flickering animation.

## Best Practices

- Chỉ dùng các negative prompt cần thiết.
- Kết hợp với Modifier Library.
- Điều chỉnh theo từng nền tảng AI Video.
- Luôn kiểm tra tính nhất quán nhân vật.

## Dependencies

- PCL-034 Prompt Blocks
- PCL-035 Modifier Library
