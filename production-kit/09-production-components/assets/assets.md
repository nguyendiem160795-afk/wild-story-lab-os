# Assets

## Purpose

Thư mục assets lưu trữ các tài nguyên dùng chung của Module 09.

## Asset Types

- Reference Images
- Camera Diagrams
- Lighting Setups
- Composition Guides
- Prompt Assets
- Icons
- Visual References

## Naming Convention

PCL-<ID>-<AssetName>.<ext>

Example:

PCL-010-ShotDiagram.png
PCL-011-LensChart.png
PCL-028-HookReference.jpg
