# PCL-027 Smoke FX Library

## Metadata

ID: PCL-027
Category: FX Components
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa các hiệu ứng khói để tăng chiều sâu không gian, tạo bầu không khí và hỗ trợ kể chuyện điện ảnh.

## Smoke FX Types

### Natural Smoke
- Campfire Smoke
- Chimney Smoke
- Steam
- Morning Mist

### Cinematic Smoke
- Volumetric Smoke
- Fog Layer
- Ground Fog
- Atmospheric Haze

### Action Smoke
- Explosion Smoke
- Dust Cloud
- Tire Smoke
- Impact Smoke

### Fantasy Smoke
- Magic Smoke
- Colored Smoke
- Shadow Smoke
- Mystic Mist

## Prompt Example

Soft volumetric smoke drifting through a forest, warm sunrise light rays, subtle atmospheric haze, cinematic depth, Pixar-quality rendering.

## Best Practices

- Sử dụng khói để tăng chiều sâu thay vì che khuất chủ thể.
- Đồng bộ với Lighting và Weather.
- Điều chỉnh mật độ theo khoảng cách camera.
- Kết hợp Particle để tạo hiệu ứng tự nhiên.
