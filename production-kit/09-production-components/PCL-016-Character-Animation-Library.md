# PCL-016 Character Animation Library

## Metadata

ID: PCL-016
Category: Character Animation
Version: 1.0.0
Status: Active

## Purpose

Chuẩn hóa các kiểu chuyển động toàn thân của nhân vật để đảm bảo tính nhất quán giữa các cảnh và các AI Video platform.

## Animation Types

- Idle
- Walk
- Run
- Jump
- Sit
- Stand Up
- Wave
- Dance
- Point
- Pick Up
- Put Down
- Celebrate
- Sneak
- Fall
- Turn Around

## Motion Principles

- Anticipation
- Follow Through
- Overlapping Action
- Ease In / Ease Out
- Secondary Motion
- Squash & Stretch
- Timing
- Spacing

## Prompt Example

Character performs a joyful walk cycle with natural arm swing, smooth body mechanics, secondary motion on scarf, Pixar-quality animation.

## Best Practices

- Giữ chuyển động mượt.
- Đồng bộ biểu cảm với hành động.
- Tránh thay đổi pose đột ngột.
- Ưu tiên chuyển động đọc được ở trẻ em.
